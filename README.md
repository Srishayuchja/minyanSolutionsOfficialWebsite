# Miniyan Solutions (Pvt) Ltd — Website

Official website for Miniyan Solutions (Pvt) Ltd. A static site built with plain HTML, CSS, and JavaScript.

## Structure

- `index.html` — main page
- `style.css` — styles
- `script.js` — scripts
- `images/` — site assets and icons

## Running locally

Just open `index.html` in a browser, or serve the folder with any static file server, e.g.:

```
npx serve .
```
